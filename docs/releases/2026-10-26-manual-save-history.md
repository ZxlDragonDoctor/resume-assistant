# 手动保存与历史简历预览（2026-10-26）

## 使用方式

- 编辑、排版、添加/删除/排序/隐藏模块和应用 AI 建议均为未保存草稿。
- 点击顶部“保存”或 Ctrl/Cmd+S 后才提交整份简历，每次成功保存生成历史记录。
- 顶部撤销、重做、放弃修改，以及 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Y，可管理当前草稿。
- 版本页签中点击记录，可浏览整份分页简历、时间、备注和与草稿的差异。
- “恢复到编辑区”先加载可撤销草稿，确认后点击保存才正式回滚。
- 离开编辑器会提示未保存内容；保存中等待本次请求完成。关闭/刷新由浏览器提示，放弃草稿后不能恢复未保存内容。
- 分享链接只展示最近保存内容。导出仍可使用当前预览草稿。

## 实现与边界

- 前端分离草稿与服务器基线，最多保留 100 步内存撤销记录，连续输入按 600ms 分组。
- 整份保存接口在同一事务中提交元信息、全部模块和历史快照。保存失败保留草稿，保存期间的新编辑保留为后续未保存修改。
- 校验所有权、模块 UUID 归属、负载限制及 expectedUpdatedAt；并发修改返回 409，不覆盖其他窗口内容。
- 第一次保存补建保存前的基线版本，保留原有简历内容；后续保存沿用系统历史。
- 新增受权限保护的历史详情接口，兼容旧快照的 JSON 字符串和缺省字段。
- 数据库修订触发器仅为文档修改推进 updated_at，分享开关和浏览计数不会制造冲突。
- 未保存内容只在当前编辑会话中保留；历史预览使用保存的内容、排版及对应模板配置。
