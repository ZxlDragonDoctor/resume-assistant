# 手动保存与历史简历预览

## 已确认范围

- 编辑内容、样式、模块操作和 AI 应用只更新内存草稿。
- 保存按钮或 Ctrl/Cmd+S 原子提交全部内容，并生成历史版本。
- 撤销/重做覆盖内容、模块和排版；放弃修改恢复最近保存内容。
- 切换页面及关闭窗口提示未保存内容，保存进行中阻止直接放弃离开。
- 历史面板点击记录查看完整分页简历、时间、备注及与草稿的差异；恢复先加载可撤销草稿，保存后生效。

## 实现

1. Zustand 分离 current/saved，维护最多 100 步撤销记录，同模块连续输入按 600ms 分组。
2. PUT /api/resumes/{id}/content 使用事务替换完整内容、校验归属及修订时间，保存失败保留草稿，冲突返回 409。
3. GET /api/resumes/{id}/versions/{versionId} 读取并规范化历史快照，保护所有权。
4. PostgreSQL 内容修订触发器排除浏览计数和分享开关，避免分享访问误报编辑冲突。
5. 保存中继续输入保留后续草稿；旧请求不能覆盖已切换的简历。

## 验收

- 前端状态回归、历史差异回归、TypeScript 与生产构建。
- Java 接口参数、权限、事务失败回滚、并发保存冲突与旧快照兼容。
- 本地浏览器：编辑零后台写入，撤销重做，放弃，失败重试，离开提醒，历史只读预览、恢复草稿。
- 正式环境：临时账号与简历，真实保存/版本读取/冲突及分享访问后的保存，验收后删除测试数据。
